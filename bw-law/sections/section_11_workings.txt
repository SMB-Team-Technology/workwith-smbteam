OVERRIDE APPLIED: Transcript-Stated Need Override #1 — Call-Purpose Override.

Rationale: The research notes state explicitly, at the top of the document
under "STATED CALL FOCUS — READ FIRST," that this discovery call was NOT a
standard marketing/intake growth call. The prospect's stated goal is scaling
from ~$200k to $500k by fixing HIRING and OPERATIONS. The two products
actually proposed and discussed on the call were (1) coaching on
hiring/systems/workflow (~$2,000/month, confirmed realistic by the client)
and (2) the "AI Workforce" platform for admin automation. Marketing/lead
generation was discussed only secondarily — current lead sources (GBP,
referrals, local networking) are explicitly described as "working," and the
firm has no paid marketing history to build from or fix.

Per audit-write.md: "Do not default to Full Service Marketing just because
revenue qualifies for a tier — the firm did not ask about marketing. Check
the LAW package table and the non-marketing package table first; only add a
marketing package if the transcript shows an actual marketing/lead-gen gap
alongside the stated need." No such gap was identified on the call — the
client's own framing of GBP/referrals/networking as "working" plus zero paid
marketing history means there is no stated marketing pain point driving this
proposal. The marketing tier suggested by package_decision.json is
therefore NOT used.

This is also consistent with the "Default to recommending both a marketing
package and a non-marketing package" rule's stated exception: "A single-
product recommendation is acceptable only when the transcript clearly shows
the firm's needs are best served by one service category." That is exactly
this case.

Revenue-band re-check (medium confidence flag): Research notes state the
actual transcript figure is "~$200k in 2025" with a stated goal of $500k.
This is consistent with — not materially different from — the HubSpot-
sourced $180,000 estimate. Both figures fall within the same eligibility
bracket (under $250K). Elite Coach is NOT eligible at this revenue level
(its floor is $250K+) regardless of which of the two figures ($180K or
$200K) is used — Coach Essentials Plus is the correct fit, with mandatory
fund verification (client can cover 4 months of services) before proceeding.

AD SPEND — CONSERVATIVE AND AGGRESSIVE (INTERNAL REFERENCE ONLY)
====================================================================

Framing note: no marketing package is being sold, and per Randy Gold's
feedback the client is budget-conscious and ads are not being recommended
as part of this engagement. This math is kept here as internal reference
only — it must NOT appear in the client-facing report's "First 90 Days" or
"Phase 1" sections. If the client's situation changes and SMB Team wants to
revisit paid visibility in a later phase, this is the starting math.

CONSERVATIVE SCENARIO — $3,000/mo
- Basis: Immigration Google PPC minimum ($3,000) = platform absolute
  minimum for any paid ads ($3,000). Both floors converge at $3,000/mo.
- Blended CPL: Immigration Google Search CPL range $85-$110, midpoint
  $97.50. Conservative scenario adds 20% cushion per methodology:
  $97.50 x 1.20 = $117.00 blended CPL.
- Leads = $3,000 / $117.00 = ~25.6 leads/mo
- Close rate: 15% (not stated in transcript — default per methodology)
- Cases = 25.6 x 0.15 = ~3.8 cases/mo
- Average case value: $4,500 (midpoint of Immigration default range
  $3K-$6K — not stated in transcript, disclosed here as a default)
- Revenue = 3.8 x $4,500 = ~$17,300/mo
- Return = $17,300 / $3,000 = ~5.8x

AGGRESSIVE SCENARIO — $8,300/mo (rounded from $8,333)
- 20% rule: Revenue goal $500,000 x 20% / 12 = $8,333/mo monthly marketing
  budget
- Geographic market multiplier: Gainesville, FL is not in the Tier 1-3
  city lists (not a mega market, primary high-density market, or listed
  strategic growth market) -> Tier 4, significant regional market,
  multiplier 1.0x
  $8,333 x 1.0 = $8,333/mo
- Spanish campaign multiplier: not applicable — firm's differentiator is
  Chinese/English bilingual service, not Spanish-language; no Spanish
  campaign signal in transcript
- Reverse math validation: ($500,000 / 12) / $4,500 avg case value = ~9.3
  target cases/mo -> / 15% close rate = ~61.7 required leads/mo -> x
  $97.50 blended CPL (no cushion for aggressive) = ~$6,019/mo required
  spend
- 20% rule ($8,333) is higher than reverse math ($6,019) -> use $8,333/mo,
  rounded to $8,300/mo for presentation
- No marketing package management fee to subtract (none being sold) —
  full amount is available ad spend if BW Law chooses to test it
  independently, in a later phase
- Leads = $8,300 / $97.50 (no cushion) = ~85.1 leads/mo
- Cases = 85.1 x 0.15 = ~12.8 cases/mo
- Revenue = 12.8 x $4,500 = ~$57,600/mo
- Return = $57,600 / $8,300 = ~6.9x

Both scenarios use the Immigration default average case value ($3K-$6K
range, $4,500 midpoint used) and 15% default close rate — neither was
stated in the transcript. Kept here for a future phase only — not part of
the current client-facing recommendation.
