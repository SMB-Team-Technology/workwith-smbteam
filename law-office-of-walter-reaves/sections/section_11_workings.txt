CONSERVATIVE / AGGRESSIVE AD SPEND — FULL ROI PROJECTION (internal reference only;
NOT presented as a Phase 1 spend commitment in the client-facing HTML — see Phase 2)
--------------------------------------------------------------------------------------
Revenue goal used: $500,000/year (2x current run rate, per default rule — the pre-merger
~$600,000 figure is noted as a possibly more resonant framing but $500K is the number used
for all reverse-math calculations below, per the standard default).

CONSERVATIVE — $2,000/mo (Criminal Defense LSA minimum; reactivating what the firm already
ran before pausing post-merger):
  - Blended CPL (LSA, mid $160, +20% conservative cushion) = $192
  - Leads = $2,000 / $192 ≈ 10.4 leads/month
  - Cases = 10.4 × 15% close rate ≈ 1.6 cases/month
  - Revenue = 1.6 × $4,000 avg case value ≈ $6,250/month
  - Return = $6,250 / $2,000 ≈ 3.1x

AGGRESSIVE — $12,000/mo (20% rule: $500,000 × 20% ÷ 12 = $8,333; Waco = Tier 4 market,
1.0x multiplier, no Spanish-campaign multiplier applied since not stated as needed;
reverse-math check: ($500,000/12) ÷ $4,000 avg case value ≈ 10.4 target cases/month ÷ 15%
close rate ≈ 69.4 leads/month × ~$170 blended Google Search/LSA CPL ≈ $11,800 — reverse
math is higher than the 20%-rule figure, so per rule 5 the higher number governs; rounded
to $12,000/mo):
  - Blended CPL (Google Search + LSA, mid, no cushion) ≈ $170
  - Leads = $12,000 / $170 ≈ 70.6 leads/month
  - Cases = 70.6 × 15% ≈ 10.6 cases/month
  - Revenue = 10.6 × $4,000 ≈ $42,400/month
  - Return = $42,400 / $12,000 ≈ 3.5x

Client-facing HTML presents this as a simplified Phase 2 range ($2,000–$5,000/mo to start,
1–3 cases, $4,000–$12,000/mo estimated revenue) rather than the full conservative/aggressive
breakdown above, since no marketing package is being sold in Phase 1 and the ad-spend block
is explicitly framed as a near-term "once stabilized" consideration, not a current ask.
