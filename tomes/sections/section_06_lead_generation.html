Website Audit

The Problem
  • PageSpeed scores could not be obtained this pass — the public API was rate-limited across every attempt this session — so mobile and desktop speed remain an open question worth checking live before scoping any rebuild
  • Mobile responsiveness could not be conclusively verified from the fetched content — no confirmed viewport/framework signal
  • Attorney bios are not visible on the homepage — a "Our Team" nav link exists, but individual attorney bios were not confirmed there
  • The firm's Birdeye/legacy directory listing still carries the prior name "Tomes & Hanratty PC," while the site and current branding are "Tomes Law Firm, PC"
The Positive
  • Modern, contemporary WordPress build (not a legacy/dated design) with a clear above-fold CTA — "Schedule an Appt" linked to Calendly, a visible phone number, and a "Request a Call" form
  • Video is already part of the site experience — a "Free Video" opt-in and a "Video Library" nav link — and the blog is active, with a post published as recently as June 10, 2026
The Gap
  • Without a confirmed speed score, there is no way to know how many mobile visitors are bouncing before the page even loads
  • Missing attorney bios on the homepage is a trust-signal gap right where a first-time visitor is deciding whether to call
  • A stale legacy business name on directory listings can quietly undercut how much credit Google gives the firm's own strong review profile
A website that quietly leaks trust and speed is one more thing that depends on Frances noticing it herself instead of a system catching it.
