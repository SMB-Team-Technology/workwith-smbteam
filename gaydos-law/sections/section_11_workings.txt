AD SPEND PLAN — TWO SEQUENTIAL PHASES, NOT CONSERVATIVE/AGGRESSIVE SCENARIOS
-----------------------------------------------------------------------------
Unlike the prior version of this proposal (which presented a conservative/
aggressive spend RANGE as two hypothetical scenarios), this plan is a
sequential ramp the client specifically asked for: start smaller, prove it
out, then add the second channel. Block 4 of section_11_next_steps.html is
relabeled "Phase 1 — LSA Launch" and "Phase 2 — LSA + PPC" instead of
"Conservative"/"Aggressive" to accurately reflect this. The same three-row
structure (cases, revenue, return) is kept underneath each, and the
underlying CPL methodology below still borrows the conservative (20% cushion)
approach for Phase 1 and the aggressive (no cushion) approach for Phase 2,
since Phase 1 is the more cautious, unproven starting point and Phase 2
reflects a channel mix with more historical performance data behind it.

Channel/practice-area split assumption (not stated by the client — documented
default): ad spend is split evenly 50/50 between Family Law and Probate at
every phase, and the LSA spend from Phase 1 ($2,000 to each practice area at
the $4,000/mo midpoint) is treated as staying in place in Phase 2, with the
new PPC dollars ($3,500/mo) also split evenly 50/50 across the two practice
areas ($1,750 each). This gives Phase 2: Family Law = $2,000 LSA + $1,750 PPC
= $3,750; Probate = $2,000 LSA + $1,750 PPC = $3,750. If actual performance
data shows one practice area converting meaningfully better, this split
should be revisited before Phase 2 begins.

CPL figures used (from the Client-Facing CPL Ranges table; Probate is priced

  - Family Law Google Search/PPC: $90-$110 (mid $100)

PHASE 1 — LSA LAUNCH (~$4,000/mo, midpoint of requested $3,000-$5,000 range)
  Methodology: conservative (20% CPL cushion applied)
  - Family Law: $2,000 spend / ($80 x 1.20 = $96 CPL) = 20.8 leads
    -> 20.8 x 15% close rate = 3.1 -> ~3 cases
  - Probate: $2,000 spend / ($65 x 1.20 = $78 CPL) = 25.6 leads
    -> 25.6 x 15% close rate = 3.8 -> ~4 cases
  - Total leads: ~46/mo | Total cases: ~7/mo (3 Family Law + 4 Probate)
  - Revenue: (3 x $5,000) + (4 x $20,000) = $15,000 + $80,000 = $95,000/mo
  - Return: $95,000 / $4,000 = ~23.8x

PHASE 2 — LSA + PPC (~$7,500/mo, starting ~month 3)
  Methodology: aggressive (no CPL cushion)
  - Family Law: $2,000 LSA / $80 = 25.0 leads; $1,750 PPC / $100 = 17.5 leads
    -> 42.5 leads x 15% close rate = 6.4 -> ~6 cases
  - Probate: $2,000 LSA / $65 = 30.8 leads; $1,750 PPC / $135 = 13.0 leads
    -> 43.8 leads x 15% close rate = 6.6 -> ~7 cases
  - Total leads: ~86/mo | Total cases: ~13/mo (6 Family Law + 7 Probate)
  - Revenue: (6 x $5,000) + (7 x $20,000) = $30,000 + $140,000 = $170,000/mo
  - Return: $170,000 / $7,500 = ~22.7x

CAPACITY CHECK: Phase 2's ~6 new Family Law cases/mo is well within the
client's stated 20/mo capacity. Phase 2's ~7 new Probate cases/mo is within
the client's stated 10-20/mo capacity (nearer the low end, so there is
meaningful additional headroom before capacity becomes a constraint on
